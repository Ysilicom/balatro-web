# Balatro · 小丑牌 (Web Edition)

> 🃏 可离线游玩的像素风扑克构筑游戏。单文件、零依赖，支持全屏沉浸式体验。

🎮 **在线体验 / Online Demo**: [https://ysilicom.github.io/balatro-web/](https://ysilicom.github.io/balatro-web/)

---

## 🌟 特性功能

- **全屏模式与画面适配**：
  - 顶部导航栏与主菜单均有一键 **⛶ 全屏** 切换按钮。
  - 支持快捷键 **`F`** 或 **`F11`** 一键全屏 / 退出全屏。
  - 双击背景区域快速切换全屏。
  - 「游戏选项 ☰」中支持 **画面适配** 切换：
    - `等比居中`：保持 16:10 原始设计比例，画面不变形，CRT 流动背景铺满屏幕。
    - `铺满全屏`：自适应拉伸铺满整个屏幕，0 边距沉浸体验。
  - 适配移动端/平板，支持一键横屏与全屏 Web App。
  - **支持「添加到主屏幕 / 添加到桌面」**：内置官方小丑牌风格高清游戏图标、Apple Touch Icon 与 Web App Manifest，支持 iOS、Android 与桌面 PWA 安装。
  - **字体与 UI 缩放**：在「游戏选项 ☰」中支持「标准」、「大字 (推荐)」、「特大」三档自由缩放，文字与计分数字即时响应。
- **单文件零依赖**：所有卡牌素材、矢量图（SVG）、Deck Pixel 字体、音效合成均内置于单个 HTML 文件中。
- **本地自动存档**：进度与设置自动保存在浏览器 LocalStorage，支持随时导出/导入存档 JSON 文件。
- **完整游戏机制**：52 种特色小丑牌、塔罗牌改造、星球牌升级、优惠券、盲注机制等。

## ⌨️ 快捷操作

| 按键 | 说明 |
| :--- | :--- |
| **`1` – `9`** | 快速选中对应位置的手牌 |
| **`Space`** | 出牌（Play Hand） |
| **`D`** | 弃牌（Discard） |
| **`F`** | **进入 / 退出全屏** |
| **`R`** | 按点数排序手牌 |
| **`S`** | 按花色排序手牌 |
| **`I`** | 打开牌型与当前牌局信息 |
| **`Esc`** | 打开设置选项 / 关闭弹窗 |

## 🚀 GitHub Pages 部署

本项目由单文件 `index.html` 驱动，推送到 GitHub 后开启 GitHub Pages 即可直接运行：

1. 确保代码位于仓库的 `main` 分支。
2. 在 GitHub 仓库设置中开启 **Pages**，Source 选择 **Deploy from a branch**，分支选择 `main`，目录为 `/ (root)`。
3. 访问 `https://<用户名>.github.io/<仓库名>/` 即可开始游玩。
